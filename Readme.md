# Bank System Extension (v2)

A console-based Bank Management System built in **C++** (Version 2 / Extension 1).

## Features

### Main Menu
* Show Client List
* Add New Clients
* Delete Client
* Update Client Info
* Find Client
* Transactions Menu
* Exit

### Transactions Menu
* **Deposit:** Add money to client accounts.
* **Withdraw:** Withdraw money with balance validation.
* **Total Balances:** View all balances and the total sum.
* Return to Main Menu.

## Technologies
* C++
* Vectors & Structs
* File I/O (`Clients.txt`)
* Input Validation
